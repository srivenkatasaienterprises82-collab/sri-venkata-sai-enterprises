# How to Edit Your Website — Simple Guide

Your website content (products, prices, photos, banners, and more) is edited
using a tool called the **Studio**. You don't need to write any code.

---

## 📍 Studio URL

**https://sri-venkata-sai-studio.sanity.studio**

Bookmark this page! This is where you make all changes.

---

## ⚡ Golden Rule

**Edit → Publish (green button, top right).**

If you forget to click **Publish**, the website stays old. Drafts are only
visible to you — customers never see them.

---

## ✅ Everyday Tasks

| Want to… | Do this |
|---|---|
| **Add a new phone** | Click **Phones & Products** → **Create** (top right) → fill tabs → **Publish** |
| **Change a price** | Open phone → **3. Prices tab** → type new number → **Publish** |
| **Change a photo** | Open phone → **2. Photos tab** → click image box → **Upload** → pick from computer → **Publish** |
| **Hide a phone (don't delete)** | Open phone → turn **Show on website** OFF → **Publish** |
| **Delete a phone** | Open phone → **⋯ menu** (top right) → **Delete** (prefer hiding instead) |
| **Change shop phone/address** | Click **Shop info** in menu → edit → **Publish** |
| **Change home page sections** | Click **Home page** → edit which products appear → **Publish** |
| **Add/change brand logo** | Click **Brands** → open brand → upload logo → **Publish** |
| **Add a promo banner** | Click **Banners** → **Create** → fill title, image, link → set **Active** ON → **Publish** |
| **Add an FAQ** | Click **FAQs** → **Create** → fill Question + Answer → **Publish** |
| **Add a customer review** | Click **Customer reviews** → **Create** → fill name, quote, rating → **Publish** |
| **Add a special offer** | Click **Offers** → **Create** → fill title, badge, image, discount → **Publish** |
| **Edit About Us / Privacy page** | Click **Website Pages** → open the page → edit text → **Publish** |
| **Add store photos** | Click **Store Photo Gallery** → add images + captions → **Publish** |

## 📸 Photos (Images) — Detailed

Every image field in the Studio has an **Upload** button. You can pick a photo
straight from your computer or phone — no links needed.

### Product photos
1. Open a product → go to the **2. Photos** tab
2. **Main photo** (Cover Image) — the big picture shown on product cards
3. **More photos** (Images) — the swipe gallery on the product detail page
4. Click each image box → **Upload** → pick photo from computer
5. Click **Publish** (top right)

> **To replace** an existing photo: click the current preview → **Replace** → pick new file → Publish.
> **To remove** a photo: click the image → **Clear** (🗑 icon) → Publish.

### Brand logos / Banner images / Gallery photos
Same process — click the image area, upload from computer, Publish.

### Tips
- Use `.jpg`, `.png`, or `.webp` files
- Keep each file under **3 MB** so pages load fast
- Clear, bright, well-lit photos look best on the website

### Troubleshooting
- **Red error message appears** — the file may be too large or the wrong type. Try a different `.jpg` or `.png` under 3 MB.
- **Photo doesn't appear after Publish** — hard refresh the website (Ctrl+F5). If still blank, make sure you actually uploaded the file and clicked Publish.

## 💰 Prices

- **Starting price (₹)** — the lowest price customers see on product cards
- **Price rows** under the Prices tab — add RAM + storage options
  (Example: 8GB + 128GB = ₹27,999)
- The website uses these rows when a customer selects different options
- **Ignore the "Advanced" tab** — those fields fill themselves automatically

---

## 🔄 After You Publish

1. Click **Publish** (green button, top right)
2. Open your website
3. **Hard refresh** the page (Ctrl+F5 or Cmd+Shift+R)
4. If it still looks old, wait ~10 seconds and refresh again

---

## ❌ Don't Do These

| Don't | Why |
|---|---|
| Forget to click **Publish** | Changes stay as a draft — website doesn't update |
| Change the **Slug** field | It breaks the product's web address |
| Type a new name in the **Brand** box | Pick from the list only — typed names won't work |
| Edit fields in the **Advanced** tab | They are automatic — ignore them |
| Delete items you're unsure about | Hidden is safer than deleted |

---

## 🆘 When to Ask the Developer

Contact the developer for:
- Uploading many product photos at once
- Changing colors, layout, fonts, or design
- Adding a completely new section or page type
- Fixing something that looks broken after an edit

For everyday text, price, and photo updates — you can do it yourself! 🎉

## Quick FAQ

**Q: Where do I log in?**
A: **https://sri-venkata-sai-studio.sanity.studio**

**Q: I edited something but the website didn't change.**
A: You forgot to click **Publish**. Open the item, click Publish (green button,
top right), then hard refresh the website (Ctrl+F5).

**Q: Can I upload a photo from my computer?**
A: Yes! Every image box has an **Upload** button. Click it, pick a file, done.

**Q: I made a mistake. Can I undo it?**
A: Open the item and check the history/versions. Or ask the developer to
restore the previous version.

**Q: Will my changes break the website?**
A: Normal text, price, and photo edits are safe. Avoid deleting items and
avoid editing technical-looking fields you don't recognize.
